# Titanic Survival Prediction 🚢

## Overview
This project predicts passenger survival on the Titanic using machine learning classification models.

## Workflow
- Dataset Loading (Kaggle Titanic)
- Data Cleaning & Missing Value Handling
- Data Visualization & Insights
- Feature Engineering (Encoding)
- Model Training & Comparison
- Evaluation using Confusion Matrix & ROC Curve

## Models Used
- Logistic Regression
- Random Forest Classifier

## Results
Best Model: Random Forest  
Accuracy: ~80–85%  
ROC AUC Score: Strong Performance

## How to Run
1. Download Titanic dataset from Kaggle
2. Place `train.csv` in project folder
3. Open notebook in Jupyter
4. Run all cells
